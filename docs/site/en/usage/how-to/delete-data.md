# Delete your data

This guide shows you how to delete the data the bot keeps about you on a server.

1. On the server, run `/privacy delete`.
2. The bot replies, to you only, with the list of what will be deleted.
3. Click **Delete my data**.

The bot confirms: "Your data on this server has been deleted."

If the bot replies that some of it could not be deleted, wait a moment and try again.

The deletion only applies to this server. On another server, run the command again. What is deleted is detailed in the [bot commands reference](../reference/core#privacy-delete).
