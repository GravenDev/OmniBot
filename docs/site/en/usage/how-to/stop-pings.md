# Stop being pinged by the bot

This guide shows you how to keep the bot's announcements from pinging you on a server.

1. On the server, run `/pings` with the `enabled` option set to **False**.
2. The bot replies, to you only: "The bot will no longer ping you in its announcements on this server. Your name still appears in them."

To be pinged again, run `/pings` with `enabled` set to **True**.

The setting applies to every module, on this server only. On another server, run the command again.
