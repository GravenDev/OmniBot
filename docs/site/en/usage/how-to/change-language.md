# Change the bot's language

This guide shows you how to choose the language of the bot's messages on your server.

Before you start: you must be an administrator of the server.

1. Run `/config` and pick **Global Configuration** in the `module` option.
2. Click the blue button next to **Language**.
3. Pick the language in the menu: 🇫🇷 for French, 🇬🇧 for English.

The bot's messages on this server switch to the chosen language. Text settings left at their default follow the new language too.
