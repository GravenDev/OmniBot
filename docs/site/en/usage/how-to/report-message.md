# Report a message

This guide shows you how to report a message to the server's moderators.

Before you start: an administrator must have enabled the Reports module and set its alert channel.

1. Right-click the message (long press on mobile), then choose **Apps**, **Report message**.
2. In the window that opens, write what is wrong if you wish, then submit.
3. The bot replies, to you only: "Thanks, your report was sent to the moderators."

To report faster, without a reason, react to the message with the server's report emoji (🚩 by default). The bot removes your reaction right away, without any confirmation message. If your reaction stays, the report may not have gone through: tell a moderator.

Only the moderators see who reported, unless the bot could not remove your reaction. The details are in the [Reports module reference](../reference/modules/reports).
