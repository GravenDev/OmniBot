# Reset settings to their default

This guide shows you how to put one or more settings of a module back to their default value.

Before you start: you must be an administrator of the server, and the module must be enabled.

1. Run `/config` and pick the module.
2. At the bottom of the panel, click **Reset…**. If the button is greyed out, no setting has been changed: there is nothing to do.
3. In the menu, pick the settings to reset, or **All fields**.

The bot confirms: "The selected fields were reset to their default." The reset settings show _(default)_ again.

Per-channel settings are not affected: to remove them, use **Remove** in their editor (see [Configure a module channel by channel](./channel-settings)).
