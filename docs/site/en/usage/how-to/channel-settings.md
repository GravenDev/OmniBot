# Configure a module channel by channel

This guide shows you how to add, edit or remove a setting that belongs to one channel. The **Auto React** and **Sticky Messages** modules are configured this way, as are the hubs of **Temporary Voice Channels**.

Before you start: you must be an administrator of the server, and the module must be enabled.

1. Run `/config` and pick the module.
2. Click the blue button next to the per-channel setting. An editor opens, visible to you only, with the list of channels already set.
3. Depending on what you want to do:
   - to set a new channel, click **Add**, pick the channel, fill in the fields and submit;
   - to change a channel's setting, click **Edit** next to that channel;
   - to remove a channel, click **Remove** next to that channel.

The result shows at the top of the editor. If the bot refuses, the message says why, for example a permission it lacks in the channel.

A channel already set cannot be added a second time: use **Edit**.
