# Using OmniBot

OmniBot adds features to a Discord server as **modules**: games, announcements, moderation, statistics… Each server picks its own. This part of the documentation is for server administrators and members. To develop a module, see the [developer guide](../guide/getting-started).

It is split into four parts, depending on what you are looking for:

| You want to…                   | Read                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| discover the bot step by step  | the **tutorial**: [Your first steps with OmniBot](./tutorials/first-module)                |
| get a specific task done       | the **how-to guides**, for example [Enable and configure a module](./how-to/enable-module) |
| look up a command or a setting | the **reference**: [bot commands](./reference/core) and [modules](./reference/modules/)    |
| understand how the bot works   | the **explanations**, for example [Modules, server by server](./explanation/modules)       |
