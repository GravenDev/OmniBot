# Remettre des réglages par défaut

Ce guide montre comment remettre un ou plusieurs réglages d'un module à leur valeur par défaut.

Avant de commencer : il faut être administrateur du serveur, et le module doit être activé.

1. Lancez `/config` et choisissez le module.
2. En bas du panneau, cliquez sur **Réinitialiser…**. Si le bouton est grisé, aucun réglage n'a été changé : il n'y a rien à faire.
3. Dans le menu, choisissez les réglages à remettre par défaut, ou **Tous les champs**.

Le bot confirme : « Les champs sélectionnés ont été réinitialisés à leur valeur par défaut. » Les réglages repris affichent de nouveau _(par défaut)_.

Les réglages salon par salon ne sont pas concernés : pour les retirer, utilisez **Supprimer** dans leur éditeur (voir [Régler un module salon par salon](./channel-settings)).
