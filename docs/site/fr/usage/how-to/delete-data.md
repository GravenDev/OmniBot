# Supprimer ses données

Ce guide montre comment supprimer les données que le bot garde sur vous sur un serveur.

1. Sur le serveur, lancez `/privacy delete`.
2. Le bot répond, à vous seul, avec la liste de ce qui sera supprimé.
3. Cliquez sur **Supprimer mes données**.

Le bot confirme : « Vos données sur ce serveur ont été supprimées. »

Si le bot répond qu'une partie n'a pas pu être supprimée, attendez un instant et recommencez.

La suppression ne vaut que pour ce serveur. Sur un autre serveur, relancez la commande. Le détail de ce qui est supprimé est dans la [référence des commandes du bot](../reference/core#privacy-delete).
