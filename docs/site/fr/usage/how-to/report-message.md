# Signaler un message

Ce guide montre comment signaler un message aux modérateurs du serveur.

Avant de commencer : un administrateur doit avoir activé le module Signalements et défini son salon des alertes.

1. Faites un clic droit sur le message (appui long sur mobile), puis choisissez **Applications**, **Signaler le message**.
2. Dans la fenêtre qui s'ouvre, écrivez si vous le souhaitez ce qui pose problème, puis validez.
3. Le bot répond, à vous seul : « Merci, votre signalement a été transmis aux modérateurs. »

Pour signaler plus vite, sans motif, réagissez au message avec l'emoji de signalement du serveur (🚩 par défaut). Le bot retire aussitôt votre réaction, sans message de confirmation. Si votre réaction reste, le signalement n'est peut-être pas parti : prévenez un modérateur.

Seuls les modérateurs voient qui a signalé, sauf si le bot n'a pas pu retirer votre réaction. Le détail est dans la [référence du module Signalements](../reference/modules/reports).
