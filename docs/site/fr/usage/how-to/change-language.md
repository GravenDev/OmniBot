# Changer la langue du bot

Ce guide montre comment choisir la langue des messages du bot sur votre serveur.

Avant de commencer : il faut être administrateur du serveur.

1. Lancez `/config` et choisissez **Configuration Globale** dans l'option `module`.
2. Cliquez sur le bouton bleu à côté de **Langue**.
3. Choisissez la langue dans le menu : 🇫🇷 pour le français, 🇬🇧 pour l'anglais.

Les messages du bot sur ce serveur passent dans la langue choisie. Les réglages de texte laissés par défaut suivent aussi la nouvelle langue.
