# Régler un module salon par salon

Ce guide montre comment ajouter, modifier ou retirer un réglage propre à un salon. Les modules **Réactions automatiques** et **Messages collants** se règlent ainsi, comme les hubs des **Salons vocaux temporaires**.

Avant de commencer : il faut être administrateur du serveur, et le module doit être activé.

1. Lancez `/config` et choisissez le module.
2. Cliquez sur le bouton bleu à côté du réglage par salon. Un éditeur s'ouvre, visible de vous seul, avec la liste des salons déjà réglés.
3. Selon ce que vous voulez faire :
   - pour régler un nouveau salon, cliquez sur **Ajouter**, choisissez le salon, remplissez les champs et validez ;
   - pour changer le réglage d'un salon, cliquez sur **Modifier** à côté de ce salon ;
   - pour retirer un salon, cliquez sur **Supprimer** à côté de ce salon.

Le résultat s'affiche en haut de l'éditeur. Si le bot refuse, le message dit pourquoi, par exemple une permission qui lui manque dans le salon.

Un salon déjà réglé ne peut pas être ajouté une deuxième fois : utilisez **Modifier**.
