# Ne plus être mentionné par le bot

Ce guide montre comment empêcher les annonces du bot de vous mentionner sur un serveur.

1. Sur le serveur, lancez `/pings` avec l'option `enabled` sur **False**.
2. Le bot répond, à vous seul : « Le bot ne vous mentionnera plus dans ses annonces sur ce serveur. Votre nom y reste affiché. »

Pour être de nouveau mentionné, lancez `/pings` avec `enabled` sur **True**.

Le réglage vaut pour tous les modules, sur ce serveur seulement. Sur un autre serveur, relancez la commande.
