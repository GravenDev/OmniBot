# Désactiver un module

Ce guide montre comment désactiver un module sur votre serveur.

Avant de commencer : il faut être administrateur du serveur.

1. Lancez `/modules`.
2. Trouvez le module, marqué ✅.
3. Cliquez sur **Désactiver**.

Le plus souvent, le module passe aussitôt à ❌. Sa configuration et ses données sont gardées : en le réactivant, vous retrouvez vos réglages.

Un module marqué 🚫 est indisponible : son bouton est grisé et il ne peut pas être désactivé tant que l'opérateur du bot n'a pas récupéré auprès de Discord la permission qui lui manque (voir [Les modules indisponibles](../explanation/modules#les-modules-indisponibles)).

Si un avertissement « Désactiver … ? » s'affiche à la place, désactiver ce module supprime des données que vous ne pourrez pas restaurer. C'est le cas des **Anniversaires** et de l'**Ancienneté**. L'avertissement dit ce qui sera supprimé :

- pour confirmer, cliquez sur **Désactiver et supprimer** ;
- pour garder le module et ses données, cliquez sur **Annuler**.
