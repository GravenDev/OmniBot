# Créer et gérer son salon vocal temporaire

Ce guide montre comment obtenir votre propre salon vocal temporaire et le régler depuis son panneau de contrôle.

Avant de commencer : un administrateur a activé le module **Salons vocaux temporaires** et défini au moins un hub avec `/config temp-voice`.

1. Rejoignez le salon vocal hub. Le bot crée votre salon, vous y déplace et publie un panneau de contrôle dans son chat textuel.
2. Pour choisir qui peut entrer, ouvrez le menu **Qui peut rejoindre ?** du panneau et choisissez **Ouvert**, **Sur invitation** ou **Privé**.
3. Pour renommer le salon ou limiter le nombre de membres, cliquez sur **Nom et limite**, remplissez le formulaire et validez.
4. Pour laisser entrer un ami quand le salon est sur invitation ou privé, cliquez sur **Membres**, puis choisissez-le dans le menu **Inviter**. Pour le prévenir, cliquez ensuite sur **Prévenir par message privé**.
5. Pour empêcher quelqu'un de voir ou de rejoindre le salon, cliquez sur **Membres**, puis choisissez-le dans le menu **Bloquer**.
6. Pour donner le salon à un autre membre présent, cliquez sur **Transférer** et choisissez-le.
7. Quittez le salon quand vous avez fini. Il est supprimé dès qu'il est vide.

Chaque action affiche un message visible de vous seul qui confirme le changement, et le panneau se met à jour. Votre nom, votre limite, votre mode d'accès et vos listes sont repris à votre prochain salon.

Tous les boutons et menus du panneau sont décrits dans la [référence du module](../reference/modules/temp-voice).
