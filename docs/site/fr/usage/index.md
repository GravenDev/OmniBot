# Utiliser OmniBot

OmniBot ajoute des fonctionnalités à un serveur Discord sous forme de **modules** : jeux, annonces, modération, statistiques… Chaque serveur choisit les siens. Cette partie de la documentation s'adresse aux administrateurs de serveur et aux membres. Pour développer un module, voir le [guide du développeur](../guide/getting-started).

Elle est rangée en quatre parties, selon ce que vous cherchez :

| Vous voulez…                         | Lisez                                                                                           |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| découvrir le bot pas à pas           | le **tutoriel** : [Vos premiers pas avec OmniBot](./tutorials/first-module)                     |
| faire une tâche précise              | les **guides pratiques**, par exemple [Activer et configurer un module](./how-to/enable-module) |
| connaître une commande ou un réglage | la **référence** : [commandes du bot](./reference/core) et [modules](./reference/modules/)      |
| comprendre comment le bot fonctionne | les **explications**, par exemple [Les modules, serveur par serveur](./explanation/modules)     |
